このノートは、Phyrion 氏の証明のうち、組合せの層を説明する。この層は、集合 $`\alpha`$、順序 $`\lt`$、定義域 $`D`$、関係 $`R`$ を引数に取り（§2）、$`\alpha`$ の元が何であるかは使わずに、それらについての 6 つの仮定から展開の整礎性を示す。このリポジトリは、この層の定理をそのまま使う。

## 1. 図式

**定義（アトム）.** **アトム** は 4 つの自然数の組 $`e = (k, r, p, q) \in \mathbb N^4`$ である。親子の辺（[05](05-1y-mountain.md) §3）1 本を表す。

- $`k \in \mathbb N`$：層の番号。
- $`r \in \mathbb N`$：根の列の番号。辺のある行で、子の成分の根になっている列である。行の番号ではない。[05](05-1y-mountain.md) では行を $`r`$ と書いたが、このノートでは $`r`$ を根の列に使い、行を $`\ell`$ と書く。
- $`p \in \mathbb N`$：親の列の番号。
- $`q \in \mathbb N`$：子の列の番号。

どれも番号（自然数）である。列に付けるラベルは §2 で定義する。

サイズ $`n`$ で **妥当** とは $`r \le p \lt q \lt n`$ のことである。

**定義（図式）.** **図式** は、サイズ $`n`$ と、妥当なアトムの有限リストの組である。$`n \in \mathbb N`$ は列の個数で、列の番号は $`0, 1, \ldots, n - 1`$ である。図式 $`G`$ のアトムのリストに $`e`$ が入ることを $`e \in G`$ と書く。

- 式 $`s = (s_0, \ldots, s_{n-1})`$ の図式では、$`n`$ は式の長さである。
- 山のどの層のどの行も、同じ列 $`0, \ldots, n - 1`$ を持つ。行ごとに列の個数が変わるわけではない。上の行ほど列が少なく見えるのは、値 0 の列を「その行に無い」と読むからである（[05](05-1y-mountain.md) §3）。そのような列も番号は残っている。

**定義（接頭辞）.** $`m \le n`$ とする。サイズ $`n`$ の図式 $`G`$ の **サイズ $`m`$ の接頭辞** とは、$`G`$ のアトム $`(k, r, p, q)`$ のうち $`q \lt m`$ のものだけを残した、サイズ $`m`$ の図式である。

**式の図式.** 式 $`s`$ の図式 $`G(s)`$ は、すべての層、すべての行の親子の辺を 1 つずつアトムにしたものである。層 $`k`$、行 $`\ell`$ で列 $`c`$ の親が $`p`$ なら、アトム

```math
(k,\ \mathrm{root}_{k,\ell}(c),\ p,\ c)
```

を入れる。$`\mathrm{root}_{k,\ell}(c)`$ は層 $`k`$、行 $`\ell`$ での $`c`$ の成分の根（[05](05-1y-mountain.md) §3）である。

| 式 | アトム $`(k, r, p, q)`$ |
|---|---|
| $`(1, 2, 2)`$ | $`(0,0,0,1)`$、$`(0,0,0,2)`$ |
| $`(1, 2, 4)`$ | $`(0,0,0,1)`$、$`(0,0,1,2)`$、$`(0,1,1,2)`$ |
| $`(1, 3)`$ | $`(0,0,0,1)`$、$`(1,0,0,1)`$ |

**例（$`(1, 2, 4)`$ のアトム）.** まず層 0 の山を作る（[05](05-1y-mountain.md) §2、§3）。表の「$`v \leftarrow p`$」は、値 $`v`$ で親が列 $`p`$ であることを表す。

| 層 0 | 列 0 | 列 1 | 列 2 |
|---|---|---|---|
| 行 2 | 0 | 0 | 1 |
| 行 1 | 0 | 1 | 2 ← 1 |
| 行 0 | 1 | 2 ← 0 | 4 ← 1 |

- 行 0：列 1 の親は、$`s_p \lt 2`$ となる最大の $`p \lt 1`$ で、列 0 である。列 2 の親は、$`s_p \lt 4`$ となる最大の $`p \lt 2`$ で、列 1 である。
- 行 1：値は差で、$`v_1 = (0,\ 2 - 1,\ 4 - 2) = (0, 1, 2)`$ である。列 1 の行 0 での祖先は列 0 だけで、その値は 0 なので、列 1 は親を持たない。列 2 の行 0 での祖先は列 1、列 0 で、$`0 \lt v_1(1) = 1 \lt 2`$ なので、親は列 1 である。
- 行 2：$`v_2 = (0, 0, 2 - 1) = (0, 0, 1)`$ である。列 2 の行 1 での祖先は列 1 だけで、その値は 0 なので、親は無い。
- 高さは列 0、1、2 の順に 0、1、2 で、頂上の値はすべて 1 である。層 1 の値は $`(1, 1, 1)`$ で、真に小さい値が無いので親は無い（[05](05-1y-mountain.md) §4）。層 1 以降にはアトムが無い。

したがって辺は層 0 の 3 本で、1 本ずつアトムになる。サイズは $`n = 3`$ である。

| 辺（層、行） | 親 $`p`$ | 子 $`q`$ | 根 $`r`$ の求め方 | アトム $`(k, r, p, q)`$ | 妥当性 $`r \le p \lt q \lt 3`$ |
|---|---|---|---|---|---|
| 層 0、行 0 | 0 | 1 | 行 0 で $`1 \to 0`$、列 0 は親が無い。根は 0 | $`(0, 0, 0, 1)`$ | $`0 \le 0 \lt 1 \lt 3`$ |
| 層 0、行 0 | 1 | 2 | 行 0 で $`2 \to 1 \to 0`$、列 0 は親が無い。根は 0 | $`(0, 0, 1, 2)`$ | $`0 \le 1 \lt 2 \lt 3`$ |
| 層 0、行 1 | 1 | 2 | 行 1 で $`2 \to 1`$、列 1 は行 1 で親が無い。根は 1 | $`(0, 1, 1, 2)`$ | $`1 \le 1 \lt 2 \lt 3`$ |

- アトムは行の番号を持たない。2 つめと 3 つめのアトムは、どちらも親 1、子 2 の辺だが、行が違うので根が違う（0 と 1）。そのため別のアトムになる。
- 3 つめのアトムの辺では、$`v_1(2) = 2 = v_1(1) + 1`$ である。これが $`(1, 2, 4)`$ の悪い根（層 0、行 1、列 1）である（[05](05-1y-mountain.md) §5）。

**例（$`(1, 3)`$ のアトム）.** この式では層 1 にも辺がある。山は [05](05-1y-mountain.md) §4 の例と同じである。

| 層 0 | 列 0 | 列 1 |
|---|---|---|
| 行 1 | 0 | 2 |
| 行 0 | 1 | 3 ← 0 |

- 行 0：列 1 の親は、$`s_p \lt 3`$ となる最大の $`p \lt 1`$ で、列 0 である。
- 行 1：$`v_1 = (0,\ 3 - 1) = (0, 2)`$ である。列 1 の行 0 での祖先は列 0 だけで、その値は 0 なので、親は無い。
- 高さは列 0 が 0、列 1 が 1 で、頂上の値は $`(1, 2)`$ である。

| 層 1 | 列 0 | 列 1 |
|---|---|---|
| 行 1 | 0 | 1 |
| 行 0 | 1 | 2 ← 0 |

- 行 0 の値は層 0 の頂上の値 $`(1, 2)`$ である。
- 列 1 の親の候補：列 1 の高さは $`h = 1`$ である。層 0 の行 $`h - 1 = 0`$ での祖先は列 0 で、その高さは $`0 = h - 1`$ なので、候補になる。値は $`0 \lt 1 \lt 2`$ なので、親は列 0 である。
- 行 1：$`v_1 = (0,\ 2 - 1) = (0, 1)`$ である。列 1 の行 0 での祖先は列 0 だけで、その値は 0 なので、親は無い。
- 頂上の値は $`(1, 1)`$ である。層 2 の値は $`(1, 1)`$ で、真に小さい値が無いので親は無い。

したがって辺は、層 0 の行 0 と、層 1 の行 0 の 2 本である。サイズは $`n = 2`$ である。

| 辺（層、行） | 親 $`p`$ | 子 $`q`$ | 根 $`r`$ の求め方 | アトム $`(k, r, p, q)`$ | 妥当性 $`r \le p \lt q \lt 2`$ |
|---|---|---|---|---|---|
| 層 0、行 0 | 0 | 1 | 行 0 で $`1 \to 0`$、列 0 は親が無い。根は 0 | $`(0, 0, 0, 1)`$ | $`0 \le 0 \lt 1 \lt 2`$ |
| 層 1、行 0 | 0 | 1 | 層 1 の行 0 で $`1 \to 0`$、列 0 は親が無い。根は 0 | $`(1, 0, 0, 1)`$ | $`0 \le 0 \lt 1 \lt 2`$ |

- 2 つのアトムは、根、親、子が同じで、層 $`k`$ だけが違う。
- 層 0 の辺では $`v_0(1) = 3 \ne v_0(0) + 1 = 2`$ なので、悪い根にならない。層 1 の辺では $`2 = 1 + 1`$ なので、列 0 が悪い根（層 1、行 0、列 0）である（[05](05-1y-mountain.md) §5）。

## 2. 表現

構造 $`(\alpha; \lt, D, R)`$ を 1 つ選んで決めておく（構造の書き方は [03](03-sigma1-elementary.md) §1）。以下の定義はすべてこの構造に対してのものである。

- $`\alpha`$ は領域である。$`\alpha`$ の元を **ラベル** と呼ぶ。下の表現で、図式の列に 1 つずつラベルを付ける。
- $`\lt`$ は $`\alpha`$ の上の順序である。
- $`D`$ は $`\alpha`$ の部分集合で、使ってよいラベルを表す。$`D(x)`$ は $`x \in D`$ のことである。
- $`R(k, \eta, a, b)`$ は 4 引数の関係である。$`k`$ は自然数、$`\eta, a, b`$ は $`\alpha`$ の元である。下の表現の定義では、$`\eta`$ に根の列（[05](05-1y-mountain.md) §3）のラベル、$`a`$ に親のラベル、$`b`$ に子のラベルが入る。そこで $`\eta`$ を **根のラベル** と呼ぶ（列の番号ではなく、$`\alpha`$ の元である）。$`R(k, \eta, a, b)`$ は「層 $`k`$、根のラベル $`\eta`$ で、$`a`$ は $`b`$ へ安定している」と読む。ここでは読み方だけで、$`R`$ の中身は問わない（§7）。

**定義（表現）.** 関数 $`f : \mathbb N \to \alpha`$ が図式 $`G`$（サイズ $`n`$）の **表現** であるとは、次の 3 つが成り立つことをいう。

1. $`i \lt n`$ なら $`D(f(i))`$。
2. $`i \lt j \lt n`$ なら $`f(i) \lt f(j)`$。
3. $`G`$ の各アトム $`(k, r, p, q)`$ で $`R(k, f(r), f(p), f(q))`$。

$`f(i)`$ を列 $`i`$ のラベルと呼ぶ。

**例.** $`(1, 2, 4)`$ の図式の表現は、次を満たす $`f`$ である。

```math
f(0) \lt f(1) \lt f(2), \quad R(0, f(0), f(0), f(1)), \quad R(0, f(0), f(1), f(2)), \quad R(0, f(1), f(1), f(2))
```

## 3. 上端への要求

**定義（上端のアトム）.** **上端のアトム** は 3 つの自然数の組 $`d = (k, r, p)`$ で、サイズ $`n`$ で妥当とは $`r \le p \lt n`$ のことである。図式の外にある点のラベル $`\beta \in \alpha`$ を **上端** と呼ぶ。関数 $`f : \mathbb N \to \alpha`$ について、$`d`$ が上端 $`\beta`$ について成り立つとは、$`R(k, f(r), f(p), \beta)`$ のことである。

上端のアトムは、図式の外にある点 $`\beta`$ への辺である。展開（[05](05-1y-mountain.md) §6）では、古い最後の列のラベルが $`\beta`$ になる。

**ふつうのアトムとの違い.** 上端のアトムは、アトム $`(k, r, p, q)`$ から子 $`q`$ を除いたものである。子は図式の列ではなく、図式の外の点で、そのラベルを $`\beta`$ と書く。

| | アトム | 上端のアトム |
|---|---|---|
| 形 | $`(k, r, p, q)`$ | $`(k, r, p)`$ |
| 子 | 図式の列 $`q`$ | 図式の外の点（ラベル $`\beta`$） |
| 妥当 | $`r \le p \lt q \lt n`$ | $`r \le p \lt n`$ |
| 成り立つ | $`R(k, f(r), f(p), f(q))`$ | $`R(k, f(r), f(p), \beta)`$ |

**例 1（形）.** $`(1, 2, 4)`$ のアトムは $`(0, 0, 0, 1)`$、$`(0, 0, 1, 2)`$、$`(0, 1, 1, 2)`$ である（§1）。最後の列 2 を除いて、列 0、1 だけの図式（サイズ 2）を考える。列 2 への 2 本の辺は、子が図式の外に出るので、上端のアトムとして書く。

- $`(0, 0, 1)`$：成り立つとは $`R(0, f(0), f(1), \beta)`$ のこと。
- $`(0, 1, 1)`$：成り立つとは $`R(0, f(1), f(1), \beta)`$ のこと。

ここで $`\beta = f(2)`$ は、外に出た列 2 のラベルである。

**定義（要求）.** §4 の有限反映に、図式 $`G`$ とは別に渡す上端のアトム $`d = (k_d, r_d, p_d)`$ を **要求** と呼ぶ。要求の有限リストを $`\mathrm{needs}`$ と書く。有限反映は、反映の前に上端 $`\beta`$ について成り立つ要求が、反映の後も新しい上端 $`f(\mathrm{cut})`$（$`\mathrm{cut}`$ は下で定義する切れ目）について成り立つことを保証する。

**展開のステップ.** 式 $`s`$ を展開して $`s[N]`$ を作る場面を考える（展開は [05](05-1y-mountain.md) §6）。$`x`$ を $`s`$ の最後の列、悪い根を $`y`$（層 $`K`$、行 $`\ell`$）とする。$`s[N]`$ の列 $`y`$ から先は、ブロック $`0, 1, \ldots, N`$ に分かれる（[05](05-1y-mountain.md) §6）。§6 では、$`G(s)`$ の表現から $`G(s[N])`$ の表現を、ブロックを 1 つずつ足して作る。$`i = 0, 1, \ldots, N - 1`$ について、ブロック $`i + 1`$ を足す手順を **ステップ $`i`$** と呼ぶ。

**展開での要求.** 各ステップ $`i`$ で、次のように $`\mathrm{needs}`$ を作る。

- ステップ $`i`$ では、ブロック $`i`$ の最初の列 $`\mathrm{cut} := y + i \cdot (x - y)`$ を **切れ目** と呼ぶ。
- 次に足す列 $`m := x + i \cdot (x - y)`$（ブロック $`i + 1`$ の最初の列）を上端とみる。
- $`s[N]`$ の山での列 $`m`$ から親への辺を、次の範囲だけ要求にする。
  - 層 $`k \lt K`$：すべての行の辺。
  - 層 $`K`$：行 $`\ell`$ より下の行の辺。
  - 層 $`k \gt K`$：無し。

層 $`K`$、行 $`\ell`$ の辺は悪い根の辺で、要求にはしない。代わりに、関係 $`R(K, \theta, f(\mathrm{cut}), \beta)`$ を §4 の有限反映に渡す（仮定 5）。この形の関係を **制御関係** と呼ぶ。$`\theta \in \alpha`$ は、その根のラベルである。ステップ 0 では $`\theta = f(\rho)`$ である。$`\rho`$ は、層 $`K`$、行 $`\ell`$ での $`x`$ の成分の根（[05](05-1y-mountain.md) §3）である。後のステップでの $`\theta`$ は §6 で述べる。

**例 2（$`(1, 2, 4)`$ の展開のステップ 0）.** $`x = 2`$、悪い根は $`y = 1`$（層 $`K = 0`$、行 $`\ell = 1`$）、$`s[N] = (1, 2, \ldots, N + 2)`$ である。ステップ $`i = 0`$ を見る。

- 図式 $`G`$ は $`(1, 2)`$ の図式で、サイズ 2、アトムは $`(0, 0, 0, 1)`$ である。$`f`$ はもとの表現で、$`\beta = f(2)`$、切れ目は $`\mathrm{cut} = y = 1`$ である。
- 上端は列 $`m = 2`$ である。$`s[N]`$ の山で、列 2 の親は行 0 で列 1（根は列 0）、行 1 では無い。層 0 の行 $`0 \lt \ell = 1`$ だけを見るので、$`\mathrm{needs} = [(0, 0, 1)]`$ である。これはもとのアトム $`(0, 0, 1, 2)`$ から、$`\beta = f(2)`$ について成り立つ。
- もとのアトム $`(0, 1, 1, 2)`$ は悪い根の辺で、要求には入らない。制御関係 $`R(0, f(1), f(1), f(2))`$ になる。列 2 の層 0、行 1 での根は列 1 なので、$`\rho = 1`$、$`\theta = f(1)`$ である。
- 要求 $`(0, 0, 1)`$ は許される（§4 で定義する）。$`k_d = 0 = K`$、$`r_d = 0 \lt \mathrm{cut} = 1`$、$`f(0) \lt f(1) = \theta`$ だからである。
- 有限反映（§4）で得る $`g`$ は、$`g(0) = f(0)`$、$`g(1) \lt f(1)`$ で、要求は上端 $`f(\mathrm{cut}) = f(1)`$ について成り立つ。つまり $`R(0, g(0), g(1), f(1))`$ である。
- 新しい図式の列 2 には $`f(\mathrm{cut}) = f(1)`$ を付ける（§6）。ラベルは $`(g(0), g(1), f(1))`$ になる。$`(1, 2, 3)`$ の図式のアトムは $`(0, 0, 0, 1)`$ と $`(0, 0, 1, 2)`$ で、後者がちょうど上の要求である。こうして要求が、新しい図式の辺になる。

**定義（上界）.** $`n \in \mathbb N`$、関数 $`f : \mathbb N \to \alpha`$、$`\beta \in \alpha`$ とする。$`i \lt n`$ ならいつも $`f(i) \lt \beta`$ のとき、$`f`$ は $`\beta`$ で **上から押さえられる** という。

## 4. 有限反映

**定義（許される要求）.** 層 $`K \in \mathbb N`$、切れ目 $`\mathrm{cut} \in \mathbb N`$、根のラベル $`\theta \in \alpha`$、関数 $`f : \mathbb N \to \alpha`$ について、上端のアトム $`d = (k_d, r_d, p_d)`$ が **許される** とは、次のどちらかのことである。

- $`k_d \lt K`$（低い層）。
- $`k_d = K`$ かつ $`r_d \lt \mathrm{cut}`$ かつ $`f(r_d) \lt \theta`$（同じ層で、根が切れ目より前にあり、根のラベルが $`\theta`$ より小さい）。

**例.** 展開のステップ 0（§3 の「展開のステップ」）を見る。$`K`$、$`\mathrm{cut}`$、$`\theta`$ は悪い根から決まる（§3 の「展開での要求」）。$`f`$ はもとの表現で、ラベルは列の順に大きくなる。

- $`(1, 2, 4)`$：悪い根は層 $`K = 0`$、行 1、列 $`y = 1`$ で、$`\mathrm{cut} = 1`$、$`\theta = f(1)`$ である（§3 の例 2）。
- $`(1, 3)`$：悪い根は層 $`K = 1`$、行 0、列 $`y = 0`$ で（[05](05-1y-mountain.md) §5）、$`\mathrm{cut} = 0`$ である。最後の列 1 の層 1、行 0 での根は列 0 なので、$`\theta = f(0)`$ である。要求は、$`s[N]`$ の列 1 から親への層 0 の辺である。$`(1, 3)[2] = (1, 2, 4)`$ の列 1 の親は、層 0 の行 0 で列 0（根は列 0）、行 1 では無い。よって $`\mathrm{needs} = [(0, 0, 0)]`$ である。

| 式 | 上端のアトム $`d`$ | 許されるか | 理由 |
|---|---|---|---|
| $`(1, 2, 4)`$ | $`(0, 0, 1)`$ | 許される（2 つめ） | $`k_d = 0 = K`$、$`r_d = 0 \lt 1 = \mathrm{cut}`$、$`f(0) \lt f(1) = \theta`$ |
| $`(1, 2, 4)`$ | $`(0, 1, 1)`$ | 許されない | $`k_d = K`$ だが $`r_d = 1`$ は $`\mathrm{cut} = 1`$ より前にない |
| $`(1, 3)`$ | $`(0, 0, 0)`$ | 許される（1 つめ） | $`k_d = 0 \lt 1 = K`$。根やラベルの条件は要らない |
| $`(1, 3)`$ | $`(1, 0, 0)`$ | 許されない | $`k_d = K`$ だが $`r_d = 0`$ は $`\mathrm{cut} = 0`$ より前にない |

許されない 2 つは、どちらも悪い根の辺（$`(0, 1, 1, 2)`$ と $`(1, 0, 0, 1)`$）から子を除いたものである。これらの辺は要求にせず、制御関係として渡す。

**定義（有限反映）.** 構造 $`(\alpha; \lt, D, R)`$（§2）が **有限反映** を満たすとは、次が成り立つことをいう。

任意の図式 $`G`$、関数 $`f : \mathbb N \to \alpha`$、自然数 $`\mathrm{cut}, K`$、ラベル $`\theta, \beta \in \alpha`$、上端のアトムのリスト $`\mathrm{needs}`$ について、次の 8 つの仮定がすべて成り立つとする。

1. $`G`$ は図式で、サイズを $`n`$ とし、$`\mathrm{cut} \lt n`$ である。
2. $`f`$ は $`G`$ の表現である。
3. $`D(\beta)`$ である。
4. $`f`$ は $`\beta`$ で上から押さえられる。
5. 制御関係（§3）$`R(K, \theta, f(\mathrm{cut}), \beta)`$ が成り立つ。
6. 要求のリスト $`\mathrm{needs}`$ の各要素は妥当である。
7. 各要素は許される。
8. 各要素は上端 $`\beta`$ について成り立つ。

このとき、次の 4 つを満たす関数 $`g : \mathbb N \to \alpha`$ がある。

1. $`g`$ は $`G`$ の表現である。
2. $`i \lt \mathrm{cut}`$ なら $`g(i) = f(i)`$。
3. $`g`$ は $`f(\mathrm{cut})`$ で上から押さえられる。
4. 各要求は上端 $`f(\mathrm{cut})`$ について成り立つ。

**意味.** 切れ目より左のラベルは動かさない。切れ目から右のラベルを付け替えて、全部を $`f(\mathrm{cut})`$ より下に入れる。辺の条件と、上端への要求（上端を $`\beta`$ から $`f(\mathrm{cut})`$ に替えたもの）は保つ。[04](04-patterns-of-resemblance.md) §3 の有限反映の形そのものである。

## 5. 6 つの仮定

組合せの層の主定理（以下、**入口の定理**）の仮定は次の 6 つである。表の文字は $`k \in \mathbb N`$、$`\eta, \eta', a, b, c, p \in \alpha`$ を動く。

| 名前 | 内容 |
|---|---|
| 整礎性 | $`\lt`$ は整礎 |
| 推移性 | $`a \lt b`$ かつ $`b \lt c`$ なら $`a \lt c`$ |
| 狭義性 | $`R(k, \eta, a, b)`$ なら $`a \lt b`$ |
| 弱化 | $`\eta' \lt \eta`$ かつ $`R(k, \eta, p, c)`$ なら $`R(k, \eta', p, c)`$ |
| 有限反映 | $`(\alpha; \lt, D, R)`$ について §4 の有限反映が成り立つ |
| 初期表現 | どの式 $`s`$ にも、$`G(s)`$ の表現がある |

結論は「1 段の展開の関係は整礎である」（[05](05-1y-mountain.md) §7 の定理 1）である。

## 6. 末尾のラベルによる降下

**定義（末尾のラベル）.** サイズ $`n \gt 0`$ の図式の表現 $`f`$ について、最後の列のラベル $`f(n-1)`$ を $`f`$ の **末尾のラベル** と呼ぶ。

**定理（末尾のラベルが下がる）.** $`G(s)`$ に末尾のラベル $`\beta`$ の表現があり、$`s[N]`$ が空でないとする。このとき、ある $`b \lt \beta`$ で、$`G(s[N])`$ に末尾のラベル $`b`$ の表現がある。

**証明の概略.** $`x`$ を $`s`$ の最後の列とし、$`G(s)`$ を古い図式と呼ぶ。$`f`$ を、$`G(s)`$ の末尾のラベル $`\beta = f(x)`$ の表現とする。

1. 悪い根が無いとき：$`s[N]`$ は $`s`$ から最後の列を消したものである。新しい図式は古い図式の接頭辞である。同じ $`f`$ が表現で、新しい末尾のラベル $`f(x-1)`$ は $`f(x) = \beta`$ より小さい。
2. 悪い根 $`y`$（層 $`K`$、行 $`\ell`$）があるとき：
   - $`i = 0, 1, \ldots, N`$ について、$`G(s[N])`$ のサイズ $`x + i \cdot (x - y)`$ の接頭辞（§1）を $`i`$ 番目の図式と呼ぶ。$`i`$ 番目の図式は、列 $`0, \ldots, y - 1`$ とブロック $`0, \ldots, i`$ の辺からなる。$`N`$ 番目の図式は $`G(s[N])`$ そのものである。
   - $`i = 0`$ 番目の図式はサイズ $`x`$ で、古い図式の接頭辞である（最後の列 $`x`$ を含まない）。$`f`$ はその表現で、$`\beta = f(x)`$ で上から押さえられる。
   - 悪い根の辺は $`R(K, f(\rho), f(y), f(x))`$ を与える。$`\rho`$ は、層 $`K`$、行 $`\ell`$ での $`x`$ の成分の根である。これが最初の制御関係で、根のラベルは $`\theta = f(\rho)`$ である。
   - $`i`$ 番目の図式の表現を $`f_i`$ とする（$`f_0 = f`$）。ステップ $`i`$（§3）で $`i`$ 番目の図式から $`i + 1`$ 番目の図式を作るときに、有限反映を 1 回使う。切れ目はブロック $`i`$ の始まり $`\mathrm{cut} = y + i \cdot (x - y)`$ である。
   - 有限反映の仮定 8（各要求が上端 $`\beta`$ について成り立つ）は、古い最後の列 $`x`$ から親への辺 $`(k, r, p, x)`$ を使って確かめる。この辺から子 $`x`$ を除くと、上端のアトム $`(k, r, p)`$ になる（§3 の例 1 と同じ作り方）。どのステップの図式も $`\beta = f(x)`$ で上から押さえられるので、ラベル $`\beta`$ の列は図式に無い。それでこの上端のアトムは、図式の外の点 $`\beta`$ への辺として残る。
     - $`i = 0`$ では、これらの上端のアトムは $`\beta`$ について成り立つ。もとの表現で、辺 $`(k, r, p, x)`$ が成り立つからである。
     - ステップを進めるときは、これらの上端のアトムの根と親の列番号を、ラベルと同じように動かす。切れ目より左の列はそのままで、切れ目から右の列は新しいブロックへ移る。移った先には古いラベルがそのまま付くので、$`\beta`$ について成り立ち続ける。
     - ステップ $`i`$ の各要求 $`d = (k, r_d, p)`$（§3 の「展開での要求」）には、こうして動かした上端のアトムのうち、層と親が同じもの $`\tau = (k, r_\tau, p)`$ がある。根は次のどちらかである。
       - $`r_d = r_\tau`$：$`d`$ と $`\tau`$ は同じなので、$`d`$ は $`\beta`$ について成り立つ。
       - $`r_d \lt \mathrm{cut} \le r_\tau`$（要求の根が $`\tau`$ の根より前のブロックにある）：ラベルは $`f_i(r_d) \lt f_i(r_\tau)`$ である。弱化で $`R(k, f_i(r_\tau), f_i(p), \beta)`$ から $`R(k, f_i(r_d), f_i(p), \beta)`$ が出る。
   - 制御関係も同じように続く。ステップ $`i`$ の制御関係を $`R(K, f_i(\rho_i), f_i(\mathrm{cut}), \beta)`$ とする（$`\rho_0 = \rho`$、$`\rho_i \le \mathrm{cut}`$）。次のステップでは、列 $`\rho_i`$ を上と同じように動かしたものを $`\rho_{i+1}`$ とし、切れ目を次のブロックの始まりにする。どちらの列にも古いラベル $`f_i(\rho_i)`$、$`f_i(\mathrm{cut})`$ がそのまま付くので、同じ関係が次のステップの制御関係になる。根のラベルは $`\theta = f_{i+1}(\rho_{i+1})`$ である。
   - $`i`$ 番目の図式のサイズを $`m`$ とする。反映で得た $`g`$ は、切れ目より左で $`f_i`$ と等しく、全体が $`f_i(\mathrm{cut})`$ より下にある。新しい図式の列は $`m + (m - \mathrm{cut})`$ 個である。列 $`c \lt m`$ には $`g(c)`$ を、列 $`c \ge m`$ には古いラベル $`f_i(\mathrm{cut} + c - m)`$ を付ける。つまり右端に $`f_i(\mathrm{cut}), \ldots, f_i(m-1)`$ がそのまま並ぶ。こうして $`g`$ と $`f_i`$ を継ぎ合わせたラベルが、1 ブロック長い図式の表現になる。新しい図式のアトムは次の 3 種類で、どれも継ぎ合わせたラベルで成り立つ。
     - $`i`$ 番目の図式のアトム：$`g`$ が表現なので成り立つ。
     - 古いアトムの列番号を同じように動かして写したもの：移った列には古いラベルが付くので成り立つ。ただし、写したアトムの根が、写した先のブロックの列ではなく、それより前の列（列番号 $`m`$ 未満）になることがある。これが「根が前のブロックへ移る」場合である。このとき写す前の根の列 $`r`$ は切れ目以降にある。新しい根のラベルは $`f_i(\mathrm{cut})`$ より下なので、$`f_i(\mathrm{cut}) \le f_i(r)`$ より小さい。そこで弱化を使う。
     - 要求から来る辺（子が列 $`m`$）：要求は上端 $`f_i(\mathrm{cut})`$ について成り立ち、列 $`m`$ のラベルは $`f_i(\mathrm{cut})`$ なので成り立つ。
   - $`N`$ 回くり返すと、$`s[N]`$ の図式の表現で $`\beta`$ で上から押さえられるものができる。
   - 新しい末尾のラベルは $`\beta`$ より小さい。$`\square`$

**6 つの仮定の使いどころ.**

| 仮定 | 使いどころ |
|---|---|
| 整礎性 | 末尾のラベルについての帰納法 |
| 推移性 | 継ぎ合わせたラベルの順序と上界 |
| 狭義性 | 制御関係から $`f(\mathrm{cut}) \lt \beta`$ を得る |
| 弱化 | 根が前のブロックへ移る辺と、$`r_d \lt r_\tau`$ の要求 |
| 有限反映 | ブロックごとに 1 回 |
| 初期表現 | 帰納法の出発点 |

**定理（値が下がることによる整礎性）.** $`X`$ を集合、$`\to`$ を $`X`$ の上の 2 引数の関係、$`(L, \lt)`$ を整礎な順序とする。$`s \in X`$ と $`a \in L`$ の関係 $`\mathrm{valid}(s, a)`$ が次を満たすとする。

- どの $`s \in X`$ にも、$`\mathrm{valid}(s, a)`$ となる $`a \in L`$ がある。
- $`\mathrm{valid}(s, a)`$ で $`s \to t`$ なら、ある $`b \lt a`$ で $`\mathrm{valid}(t, b)`$ である。

このとき、$`\to`$ は整礎である。つまり $`s_0 \to s_1 \to s_2 \to \cdots`$ という無限列は無い。

**証明.** $`a`$ についての整礎帰納法（[02](02-well-founded.md) §2）で、「$`\mathrm{valid}(s, a)`$ なら $`s`$ は到達可能（[02](02-well-founded.md) §1）」を示す。$`s \to t`$ なら、$`b \lt a`$ で $`\mathrm{valid}(t, b)`$ となる $`b`$ があるので、帰納法の仮定から $`t`$ は到達可能である。$`\square`$

$`s`$ に付ける $`a`$ は 1 つに決まっている必要は無い。1-Y では、1 つの式に付けられる表現はたくさんある。

**整礎性.** $`\beta`$ についての整礎帰納法で、「$`G(s)`$ に末尾のラベル $`\beta`$ の表現があれば、$`s`$ は到達可能」を示す。これは上の定理の形である。空の式は 1 段の展開を持たないので、別に扱う。初期表現から、どの式にも最初のラベルが付く。よって展開の関係は整礎である。

上の定理に、次のように当てはめる。

| 一般形 | 1-Y |
|---|---|
| $`X`$ の元 | 式 $`s`$ |
| $`s \to t`$ | 自明でない 1 段の展開（$`t = s[N] \ne s`$） |
| $`(L, \lt)`$ | ラベルの順序 $`(\mathrm{Ord}, \lt)`$ |
| $`\mathrm{valid}(s, a)`$ | $`s`$ の図式に、末尾のラベルが $`a`$ の表現がある |

## 7. 意味の層に残る仕事

組合せの層は、有限反映がなぜ成り立つかを問わない。6 つの仮定を満たす $`(\alpha; \lt, D, R)`$ を与えるのが **意味の層** の仕事である。

- Phyrion 氏の意味の層：このリポジトリとは別の $`D`$ と $`R`$ を与える。
- このリポジトリの意味の層：$`\alpha = \mathrm{Ord}`$、$`D = \mathrm{True}`$（すべての $`x`$ で $`D(x)`$ が成り立つこと）、$`R`$ は [07 関係 R](07-relation-r.md) の関係である。証明は [09 義務の証明](09-obligations.md) にある。
