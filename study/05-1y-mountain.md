# 1-Y 数列と山

前提

| ノート | ここで使う言葉 |
|---|---|
| [02 整礎関係と整礎再帰](02-well-founded.md) | 整礎、辞書式順序が整礎でないこと |

このノートは、1-Y 数列とその展開の定義を説明する。定義は Phyrion 氏によるものである。

例の値は、この定義に従って計算機で計算したものである（2026-09-23）。

## 1. 式

**定義（式）.** **式** は正の整数の有限列 $`s = (s_0, \ldots, s_{n-1})`$（$`n \in \mathbb N`$）で、空か、$`s_0 = 1`$ のものである。

- 列の番号は 0 から数える。$`i`$ 番目の項を「列 $`i`$」と呼ぶ。
- **種** は $`(1, m)`$（$`m \ge 1`$ は整数）の形の式である。式は、種から展開（§6）で作れるものでなくてもよい。
- 式の順序は辞書式順序 $`\lt_{\mathrm{lex}}`$ である。真の接頭辞は小さい。[02](02-well-founded.md) §1 のとおり、この順序は式全体の上では整礎でない。

## 2. 山の行 0

式 $`s`$ から、行 $`0, 1, 2, \ldots`$ のそれぞれについて、各列の値と親を作る。この表を $`s`$ の **山** と呼ぶ。列 $`c`$ の行 $`r`$ の値を $`v_r(c)`$、親を $`\mathrm{par}_r(c)`$ と書く（$`r, c \in \mathbb N`$）。行 0 の値は $`v_0(c) := s_c`$ である。

**定義（森と祖先）.** 各列 $`c`$ に、$`c`$ より左の列を高々 1 つ、$`c`$ の **親** として与えたものを **森** と呼ぶ。森で、$`c`$ から親を 1 回以上たどって着く列を、$`c`$ の **祖先** と呼ぶ。

**定義（行 0 の親）.** 列 $`c`$ の行 0 の親は、$`p \lt c`$ かつ $`s_p \lt s_c`$ を満たす最大の $`p`$ である。無ければ親は無い。行 0 の親は森をなす。

## 3. 上の行

行 $`r`$ の値 $`v_r`$ と親 $`\mathrm{par}_r`$ から、行 $`r+1`$ を作る。

**定義（差）.** $`c`$ が行 $`r`$ で親 $`p`$ を持てば $`v_{r+1}(c) := v_r(c) - v_r(p)`$、持たなければ $`v_{r+1}(c) := 0`$ とする。

**定義（行 r+1 の親）.** $`c`$ の行 $`r+1`$ の親は、行 $`r`$ の親がなす森での $`c`$ の祖先（$`\mathrm{par}_r(c)`$、$`\mathrm{par}_r(\mathrm{par}_r(c))`$、…）のうち、$`0 \lt v_{r+1}(p) \lt v_{r+1}(c)`$ を満たす最大の $`p`$ である。

値 0 の列は「その行に無い」と読む。

**定義（高さと頂上の値）.** 列 $`c`$ の **高さ** は、$`v_r(c) \gt 0`$ となる最大の $`r`$ である。その行の値を **頂上の値** と呼ぶ。値は行ごとに真に減るので、高さは有限である。この列の高さは、[03](03-sigma1-elementary.md) §1 の構造の高さとは別のものである。

**例.** $`s = (1, 2, 4, 3)`$。表の「$`v \leftarrow p`$」は、値 $`v`$ で親が列 $`p`$ であることを表す。

| 行 | 列 0 | 列 1 | 列 2 | 列 3 |
|---|---|---|---|---|
| 2 | 0 | 0 | 1 | 0 |
| 1 | 0 | 1 | 2 ← 1 | 1 |
| 0 | 1 | 2 ← 0 | 4 ← 1 | 3 ← 1 |

- 行 0：列 3 の値 3 より小さい値を持つ最大の列は列 1（値 2）である。
- 行 1：列 3 の値は $`3 - 2 = 1`$。行 0 での祖先は列 1、列 0 である。行 1 の値は 1 と 0 で、どちらも「$`0 \lt v \lt 1`$」を満たさない。親は無い。
- 高さは左から 0, 1, 2, 1。頂上の値はどれも 1 である。

**定義（辺）.** 行 $`r`$ で列 $`c`$ の親が $`p`$ のとき、組 $`(p, c)`$ を行 $`r`$ の **親子の辺**（または単に **辺**）と呼ぶ。$`p`$ を辺の親、$`c`$ を辺の子と呼ぶ。

**定義（成分の根）.** 行 $`r`$ の辺でつながった列の集まりを、行 $`r`$ の **成分** と呼ぶ。行 $`r`$ で、列 $`c`$ から親をたどって、親の無い列に着いたとき、その列を $`c`$ の行 $`r`$ での **根** と呼ぶ。$`c`$ が親を持たなければ、根は $`c`$ 自身である。同じ成分の列は同じ根を持つ。上の例の行 1 では、列 2 の根は列 1 である。

## 4. 層

§2、§3 の山を **層 0** と呼ぶ。1-Y の山は、層 0 から層 $`1, 2, \ldots`$ を順に作って積み重ねたものである。各層は、行 0 の値と、行 0 の親がなす森を持つ。上の行は、§3 と同じ規則で作る。層 $`k`$ の山を、単に層 $`k`$ と呼ぶ。

**定義（抜き出し）.** 層 $`k`$ から層 $`k+1`$ を作る。

- 値：各列の頂上の値。
- 親の候補の森：高さ $`h \gt 0`$ の列 $`c`$ について、行 $`h - 1`$ での $`c`$ の祖先のうち、高さが $`h`$ か $`h - 1`$ である最大の列。高さ 0 の列には候補の親が無い。
- この森の中から、行 0 と同じ規則（値が正で、真に小さい、最大の祖先）で親を選ぶ。祖先は、この候補の森での祖先（§2）である。選んだ親が、層 $`k+1`$ の行 0 の親である。

列の値は層ごとに減るので、$`\max(1, \max_i s_i)`$ 個の層で十分である。

**例.** $`s = (1, 3)`$。

| 層 0 | 列 0 | 列 1 |
|---|---|---|
| 行 1 | 0 | 2 |
| 行 0 | 1 | 3 ← 0 |

列 1 の高さは 1、頂上の値は 2 である。行 1 で、列 1 の祖先は列 0 だが、その値は 0 なので親にならない。

| 層 1 | 列 0 | 列 1 |
|---|---|---|
| 行 1 | 0 | 1 |
| 行 0 | 1 | 2 ← 0 |

層 1 の行 0 の値は頂上の値 $`(1, 2)`$ である。列 1 の候補の親は列 0（行 0 での祖先で、高さ $`0 = 1 - 1`$）である。値は $`1 \lt 2`$ なので、親は列 0 である。層 2 の値は $`(1, 1)`$ で、親は無い。

$`(1, 2, 4, 3)`$ では頂上の値がすべて 1 なので、層 1 以降に親は無い。

## 5. 悪い根

**定義（悪い根）.** 最後の列を $`x`$ とする。ある層 $`k`$、行 $`r`$ で、$`x`$ が親 $`p`$ を持ち、$`v(x) = v(p) + 1`$ となるとき（$`v`$ は層 $`k`$、行 $`r`$ の値）、$`p`$ を **悪い根** と呼ぶ。

- そのような $`(k, r)`$ は高々 1 つである。
- 行 0 で $`x`$ が親を持てば、悪い根はある。行 0 で親を持たなければ、悪い根は無い。
- 悪い根の位置は（層、行、列）の組で表す。

| 式 | 悪い根の（層、行、列） | 理由 |
|---|---|---|
| $`(1, 2, 3)`$ | $`(0, 0, 1)`$ | 行 0 で $`3 = 2 + 1`$ |
| $`(1, 2, 4)`$ | $`(0, 1, 1)`$ | 行 0 で $`4 \ne 2 + 1`$、行 1 で $`2 = 1 + 1`$ |
| $`(1, 3)`$ | $`(1, 0, 0)`$ | 層 0 では差が 2。層 1 の行 0 で $`2 = 1 + 1`$ |
| $`(1, 2, 4, 3)`$ | $`(0, 0, 1)`$ | 行 0 で $`3 = 2 + 1`$ |

## 6. 展開

**定義（展開 $`s[N]`$）.** $`N \in \mathbb N`$ はコピーの回数である。最後の列を $`x`$ とする。

- 悪い根が無いとき：最後の列を消す。$`s[N] = (s_0, \ldots, s_{x-1})`$。
- 悪い根 $`z`$ があるとき：長さ $`x + N \cdot (x - z)`$ の式を作る。列 $`z`$ から $`x - 1`$ までの区間（長さ $`x - z`$）を $`N`$ 回コピーする。ただし値をそのまま写すのではない。各層の山（親の森）を写し、そこから値を組み立て直す。

**定義（ブロック）.** 悪い根 $`z`$ があるとき、$`i = 0, 1, \ldots, N`$ について、$`s[N]`$ の列 $`z + i \cdot (x - z)`$ から $`z + (i+1) \cdot (x - z) - 1`$ までを **ブロック $`i`$** と呼ぶ。ブロック 0 はもとの区間で、ブロック $`1, \ldots, N`$ がそのコピーである。$`s[N]`$ は、列 $`0, \ldots, z - 1`$ のあとにブロック $`0, \ldots, N`$ を並べたものである。例えば $`(1, 2, 2)[2] = (1, 2, 1, 2, 1, 2)`$ では $`z = 0`$、$`x = 2`$ で、ブロック 0、1、2 は列 $`\{0, 1\}`$、$`\{2, 3\}`$、$`\{4, 5\}`$ である。

| 式 $`s`$ | $`N`$ | $`s[N]`$ |
|---|---|---|
| $`(1)`$ | 5 | $`()`$ |
| $`(1, 2)`$ | 3 | $`(1, 1, 1, 1)`$ |
| $`(1, 2, 3)`$ | 0 | $`(1, 2)`$ |
| $`(1, 2, 3)`$ | 1 | $`(1, 2, 2)`$ |
| $`(1, 2, 3)`$ | 2 | $`(1, 2, 2, 2)`$ |
| $`(1, 2, 2)`$ | 2 | $`(1, 2, 1, 2, 1, 2)`$ |
| $`(1, 2, 4)`$ | 2 | $`(1, 2, 3, 4)`$ |
| $`(1, 2, 4)`$ | 3 | $`(1, 2, 3, 4, 5)`$ |
| $`(1, 3)`$ | 2 | $`(1, 2, 4)`$ |
| $`(1, 3)`$ | 3 | $`(1, 2, 4, 8)`$ |
| $`(1, 2, 4, 3)`$ | 2 | $`(1, 2, 4, 2, 4, 2, 4)`$ |

$`(1, 3)`$ の例では、コピーが層 1 で起きる。そのため値は単純な繰り返しにならない。

## 7. 1 段の展開と最終定理

**定義（1 段の展開）.** $`t`$ が $`s`$ の自明でない 1 段の展開であるとは、ある $`N \in \mathbb N`$ で $`s[N] = t`$ で、$`t \ne s`$ であることをいう。

- 空の式は、展開しても空のままである。だから空の式から 1 段の展開は無い。
- 1 段の展開は辞書式順序を下げる。しかし辞書式順序は整礎でないので、これだけでは停止は出ない。

**定義（届く）.** $`s = t_0, t_1, \ldots, t_j = t`$（$`j \in \mathbb N`$）で、各 $`t_{i+1}`$ が $`t_i`$ の展開 $`t_i[N_i]`$（$`N_i \in \mathbb N`$）であるものがあるとき、$`t`$ は $`s`$ から **届く** といい、$`s \to^{*} t`$ と書く。$`j = 0`$ も許すので、$`s`$ は $`s`$ から届く。$`s`$ から届く式を $`s`$ の **子孫** と呼ぶ。

このリポジトリの最終定理（[README](../README.md)「最終定理 4 つ」）は次のとおりである。

1. 定理 1：1 段の展開の関係は整礎である。
2. 定理 2：種から届く式の集合は、辞書式順序で整列する。
3. 定理 3：どの式でも、その子孫の集合は、辞書式順序で整列する。
4. 定理 4：コピーの回数をどう選んでも、展開を続けると空の式に着く。

定理 2〜4 は定理 1 から組合せの議論だけで出る。定理 1 の証明が [06](06-combinatorial-layer.md) 以降の話題である。
